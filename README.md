# XyPlayer 智能解析 v4.21

## 项目简介
XyPlayer 智能解析是一款功能强大的视频解析系统，无需安装数据库，上传即可使用，支持多种播放器和模板切换，提供丰富的后台管理功能。

## 主要特征

### 核心特性
- **无需安装**：无需安装，无需数据库，上传即用
- **强大的后台管理**：支持修改各项配置
- **模板切换**：内置两套模版，可随意切换
- **播放器切换**：内置多种播放器（dplayer, ckplayer, H5等），可随意切换
- **缓存支持**：支持文件缓存或Redis缓存，实现视频秒加载
- **多平台对接**：支持QQ群机器人对接和微信个人公众号对接
- **安全保障**：支持反调试，保证数据安全

## 功能模块

### 1. 防火墙模块
- 可以用来授权网站、APP等

### 2. 链接跳转模块
- 可以指定视频链接跳转到设置链接

### 3. 对接模块
- 可以对接一次解析为我所用
- 提供CMS一次解析插件配合使用

### 4. 云播放模块
- 根据视频链接或视频标题搜索播放资源站资源
- 无广告，可自定义资源站
- 支持剧集连播

### 5. 解析模块
- 可自定义第三方解析接口

### 6. 广告过滤模块
- 支持自定义规则

## 安装和使用方法

1. **上传文件**：上传upload目录下的文件到网站根目录
2. **环境要求**：建议PHP版本为7.4+
3. **后台访问**：后台的访问地址为 `/admin`
4. **初始账户**：
   - 用户名：admin
